CT05 — Validação da Tela do Pedido QR Code

Status: Aprovado
Tipo de teste: Teste funcional
Módulo: Tela do Pedido QR Code

1. Objetivo

Validar a geração e a leitura do QR Code na tela do pedido, verificando se o código direciona para a autorização do pedido correto e se o fluxo de aprovação funciona conforme esperado.

2. Pré-condições

* Possuir acesso ao ambiente de testes.
* Ter um pedido de teste disponível.
* Ter um dispositivo móvel para realizar a leitura do QR Code.

3. Cenário de teste

CT05.01 — Geração, leitura e validação do QR Code

Procedimento

1. Acessar a tela do pedido de teste.
2. Gerar o QR Code correspondente ao pedido.
3. Verificar se o QR Code é exibido corretamente na tela.
4. Realizar a leitura do código utilizando um dispositivo móvel.
5. Verificar se o acesso direciona para a autorização do pedido correto.
6. Prosseguir com o fluxo de aprovação.
7. Verificar se o processo de aprovação é concluído normalmente.
8. Validar se o logotipo é exibido corretamente na interface acessada pelo dispositivo móvel.

4. Resultado esperado

* O QR Code deve ser gerado e exibido corretamente.
* A leitura pelo dispositivo móvel deve funcionar.
* O código deve direcionar para a autorização do pedido correspondente.
* O fluxo de aprovação deve ocorrer normalmente.
* O logotipo deve ser exibido corretamente.

5. Resultado obtido

O QR Code foi gerado e lido com sucesso pelo dispositivo móvel. O acesso direcionou para a autorização do pedido correto, o fluxo de aprovação ocorreu normalmente e o logotipo foi exibido conforme esperado.

Resultado: Aprovado.

6. Evidências

* Captura de tela do pedido com o QR Code gerado.
* Evidência da leitura do QR Code pelo dispositivo móvel.
* Captura da tela de autorização do pedido.
* Evidência da conclusão do fluxo de aprovação e da exibição do logotipo.
