Testes de API — Postman

Nesta seção estão reunidas as atividades relacionadas à validação de APIs e integrações, utilizando o Postman para realizar requisições e analisar as respostas dos serviços.

O objetivo é compreender o funcionamento das APIs, validar integrações e verificar se os dados e comportamentos retornados estão de acordo com o esperado.

Principais atividades:

  °Execução de requisições HTTP.
  °Validação de métodos GET, POST, PUT e DELETE.
  °Análise de códigos de status HTTP.
  °Validação de respostas JSON e XML.
  °Testes de integrações e webhooks.
  °Análise de cenários positivos e negativos.
  °Estudos de autenticação, parâmetros e headers.
